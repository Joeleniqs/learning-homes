How to use this home

Read a topic once for the picture, then once for the code in your main language, then switch tabs and compare another language: the differences teach the concept. Do the self-checks, apply one idea to real code the same week, and mark a topic mastered only when you can explain the trade-off and name a case where you would not use it.
