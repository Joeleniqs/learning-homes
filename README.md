# Learning Homes

Visual, interactive study guides, published at **https://joeleniqs.github.io/learning-homes/**.

- **DSA Home**: data structures and algorithms, with step-through visualizers, reusable templates and problem ladders from basic to very hard.
- **Code Excellence Home**: cross-language engineering craft, including design patterns, dependency injection, performance, API design, request pipelines and middleware, caching, resilience and testing.

## Progress

Progress (mastered topics, theme and preferred language) is saved in your browser's local storage. There's no account and no server. To back up progress or move it to another device, use **Export progress** and **Import progress** on each home page. Import merges the file's mastered topics with the ones already in this browser.

## How this repo is produced

The site is static HTML generated by each home's own build. GitHub Pages serves the `main` branch root.

To publish an update:

1. Edit content in the home's source folder and check it locally (`.venv\Scripts\python.exe build.py`). The source folders sit next to this repo, each with its own `.venv`.
2. From this repo, run `python publish.py` (use a Python that has `playwright`). For each home it runs `build.py --target public --out <staging>`, which links only to homes marked `"public": true` and adds a link back to this landing page. It then scans the output and this repo's own files for private references, checks the engine files are identical across homes, checks the pages in headless Chrome and regenerates the landing page. Only if all of that passes does it swap the new output into the repo. Add `--full` to check every page in light and dark themes, or `--no-check` to skip the browser check.
3. Review with `git status`, then commit and push. Pages redeploys in a minute or two.

`publish.py` needs a gitignored `publish.local.json` listing extra private names to scan for: `{"private_patterns": ["<regex>", ...]}`. It refuses to publish without one, and refuses if an earlier failed run left a `.publish-old-*` folder (that folder holds the previous output).

Progress keys are `<home>-mastered`, `<home>-theme` and `<home>-lang`, where `<home>` is the `data-home` value (`dsa-home`, `code-excellence-home`). Avoid renaming topic slugs: a mastered flag stored under the old slug is kept (and exported), but no longer counts toward the renamed topic.
